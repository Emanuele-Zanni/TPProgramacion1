## 8. Validar fechas correctamente

Las fechas deben:

* Tener un formato único, preferentemente `dd/mm/aaaa`.
* Cumplir el patrón esperado.

* Se validaba por error nuevamente la fecha inicial al ingresar la fecha final.
* En modificaciones se permitían valores arbitrarios.

Creá una función reutilizable.

Primero validá el formato, por ejemplo con expresión regular:

```python
r"^\d{2}/\d{2}/\d{4}$"
```

Después validá la fecha real mediante `datetime.strptime()`.

Ejemplo:

```python
from datetime import datetime
import re

def convertir_fecha(fecha_texto):
    patron = r"^\d{2}/\d{2}/\d{4}$"

    if re.fullmatch(patron, fecha_texto) is None:
        raise ValueError("El formato debe ser dd/mm/aaaa.")

    return datetime.strptime(fecha_texto, "%d/%m/%Y").date()
```

La expresión regular valida el formato, pero `datetime` debe verificar que la fecha exista realmente.

Aplicá esta validación en:

* Alta de proyectos.
* Modificación de proyectos.
* Alta de tareas.
* Modificación de tareas.
* Filtros por fecha, si existen.

Integrala correctamente o reemplazala. No dejes dos funciones distintas haciendo lo mismo.

# PARTE 13 — RECURSIVIDAD

## 29. Implementar al menos tres funcionalidades recursivas

El checklist exige recursividad en al menos tres funcionalidades.

No alcanza con crear tres ejemplos desconectados del sistema. Las funciones deben estar integradas o ser utilizadas por funcionalidades reales.

Cada función recursiva debe tener:

* Caso base.
* Caso recursivo.
* Progreso hacia el caso base.
* Retorno claro.
* Prueba unitaria.
* Explicación del funcionamiento.

Implementá al menos tres de las siguientes opciones:

### Funcionalidad recursiva 1: buscar un registro por ID

```python
def buscar_por_id_recursivo(registros, id_buscado, indice=0):
    if indice >= len(registros):
        return -1

    if registros[indice][0] == id_buscado:
        return indice

    return buscar_por_id_recursivo(registros, id_buscado, indice + 1)
```

Debe utilizarse en una consulta o funcionalidad real.

### Funcionalidad recursiva 2: contar tareas de un proyecto

```python
def contar_tareas_proyecto_recursivo(tareas, id_proyecto, indice=0):
    if indice >= len(tareas):
        return 0

    cantidad_actual = 1 if tareas[indice][ID_PROYECTO] == id_proyecto else 0

    return cantidad_actual + contar_tareas_proyecto_recursivo(
        tareas,
        id_proyecto,
        indice + 1
    )
```

Puede utilizarse en estadísticas.

### Funcionalidad recursiva 3: listar o construir registros

Ejemplo:

```python
def obtener_nombres_recursivo(registros, indice=0):
    if indice >= len(registros):
        return []

    return [registros[indice][1]] + obtener_nombres_recursivo(
        registros,
        indice + 1
    )
```

Puede utilizarse en un menú, informe o consulta.

Otras posibilidades:

* Contar tareas finalizadas.
* Calcular una suma.
* Obtener el máximo de una lista.
* Recorrer una lista para verificar duplicados.
* Mostrar una estructura jerárquica.
* Calcular estadísticas.

Reglas:

* Deben ser tres funcionalidades diferentes.
* No deben ser tres variantes casi idénticas de la misma función.
* No uses recursión infinita.
* No modifiques accidentalmente la lista original.
* Documentá el caso base y el caso recursivo.
* Incluí pruebas con lista vacía, un elemento y varios elementos.
